# Noria Player — Feedback & Bugs

Noria Player est un lecteur IPTV multiplateforme (Xtream Codes / M3U), ciblant en priorité **Android** et **Android TV**, avec Live TV, VOD, Séries, Replay et EPG. L'app est actuellement en **bêta**.

⚠️ **Ce repo ne contient aucun code source.** Il sert uniquement à centraliser les retours et signalements de bugs des testeurs bêta. Le code source de l'application reste privé.

## Signaler un bug

1. **Vérifiez d'abord** dans les [Issues existantes](../../issues) si le bug a déjà été signalé — ajoutez un commentaire dessus plutôt que d'ouvrir un doublon.
2. Sinon, [ouvrez une nouvelle issue](../../issues/new/choose) en utilisant le template **Bug report**.
3. Pour une idée ou une amélioration, utilisez le template **Feature request**.
